Media Shield — WebSocket self-test

Open this page in Burp's browser (or any browser proxied through Burp) with the Media Shield extension loaded. You send a locally-generated test image over a WebSocket to an echo server; the server sends it straight back (server → client), which is the direction the shield blinds. Shield ON → the "Received" pane shows an orange placeholder. Shield OFF → it shows the original test image. The "Sent" pane is drawn locally and is never touched, so it always shows the true image for comparison.

disconnected

Any echo server works. For an offline/engagement machine, point this at a local echo instead of a public one — but note browsers often bypass the proxy for localhost/127.0.0.1, in which case Burp (and the shield) never sees the traffic. Use a real hostname routed through Burp.
